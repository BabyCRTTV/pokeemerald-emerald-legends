# Native seasonal encounters / DexNav preview

After the normal Debug ROM/ELF build, run `python3 tools/legends/native_seasonal_encounters_qa/run.py` with the ARM tools, mGBA 0.10.2 development library and Pillow installed. The mGBA CI job reuses its existing build for this step.

The original thirty-five controlled cases cover Routes 101–104 in all seasons, all-unseen and all-seen land-roster states, and Route 104's southern half. The original nineteen scenes are followed by all sixteen fully discovered land rosters, so every new visitor is captured in color as well. Each creates 256 actual wild Pokémon with the native generator and checks species/level membership, committed-vs-pending tables, the displayed unique land roster, original icon image pointers/VRAM animation frames, black-only silhouette palettes, unchanged known palettes, an unseen A-button lock, UI closure and protected state. Every real grid icon also receives two-pose hardware-sampling bounds checks: centered within one pixel, uniform shrink-only matrices and no overlap between 24px columns. The source/C regressions separately establish the original residents, precise 70/20/10 base odds, levels/rates, unavailable prior-season DexNav targets and unrelated-map fallback behavior.

A temporary callback uses controlled flags/vars in an instrumented copy of the compiled Legends Debug ROM. Screenshots are real native mGBA video-buffer pixels. This does not establish natural progression, full DexNav hunts, historical-save migration, Release interaction or Pizza Boy coverage. ROMs/ELFs/saves are never artifact paths; the private ROM is deleted even on failure. Only PNG/JSON/logs are uploaded. Preserve the approved roster/style and verify native captures before publication.

The initial run passed both game builds and ordinary native checks but the preview checker referenced an inlined private function. The checker now uses only address-taken GUI task/static state symbols and presses real A to test unseen rejection. DexNav level lookup receives an executable shipped-C regression; no game function is made public or marked noinline for instrumentation.

v0.0.64 adds 33 Surf cases on Routes 105–108 (68 total): mixed/fully discovered rosters in every season plus all-unseen selection lock. Fixtures use native Calm Water and the actual Surf avatar transition; water icons receive the same asset/palette/pose/panel checks. Native five-slot tables and generation use the water resolver, with pending-season protection and 256 creations per case.

The checker carries a byte comparator because this ROM inlines its normal constant-size comparisons and exports no standalone memcmp. Sampling verifies valid species/levels and both seasonal visitors, while exact table checks establish all residents and slots; a 1% resident is not required to occur in 256 random creations.

The v0.0.65 extension appends 34 cases, preserving all previous 68 indices: every Route109 Surf / Route110 grass / Route111 desert / Route112 grass season in mixed and fully seen states, plus all-unseen locks on Route109 and Route111 (102 cases; 26,112 real wild creations).
