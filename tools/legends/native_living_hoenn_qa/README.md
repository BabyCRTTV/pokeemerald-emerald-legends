# Native Living Hoenn regression

After building the Debug ROM/ELF and installing ARM tools, mGBA 0.10.2 development files and Pillow, run `python3 tools/legends/native_living_hoenn_qa/run.py` from any directory. The existing mGBA CI build runs it after the unchanged-ROM Quickstart smoke, reusing that build.

A private callback sets controlled flags/vars on original maps. The host waits for the exact patron menu, selects Research Notes at cursor 2 and matches the original encoded expected text. Twenty-three cases cover all eight research tiers, rescue/decline/four active-season bulletin cases (with a pending different season), and nine town-NPC fallback/milestone states. It checks script/menu closure, passable placement, and unchanged journal/claim/PC/request/active-season state. Captures come directly from the compiled Legends ROM in mGBA. Native frames retain exact pixels.

This is controlled branch execution, not natural walking/story progression, a historical-save migration test or Pizza Boy. The private ROM is deleted after success and never uploaded. Only PNGs/JSON/logs are artifact paths. Keep the external private-preview branch separate; its earlier blind button sequence did not enter Research Notes.
