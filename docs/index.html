POKÉMON EMERALD: LEGENDS
v0.0.7

A new development branch of Hoenn

Emerald, expanded carefully.

Pokémon Emerald: Legends is an unofficial fan project built on pokeemerald-expansion. The goal is to keep Emerald recognizable while adding modern quality-of-life systems, configurable mechanics, and new ideas one feature at a time.
