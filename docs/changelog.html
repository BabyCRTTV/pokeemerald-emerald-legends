EMERALD: LEGENDS // CHANGELOG
v0.0.10

Build history

What changed?

Release and Debug share the same Legends gameplay and content unless noted otherwise. Use the tabs to see the history for the build you actually play or test.

v0.0.11 October 8, 2026

Shared

  • Added real-time calendar seasons or a season change every 28 saved gameplay hours.
  • Added seasonal outdoor foliage, rain, fog, thunderstorms and mainland winter snow.
  • Preserved volcanic and desert areas, interiors, oceans and special/story weather rules.
  • Existing saves migrate automatically; the gameplay cycle continues beyond 999 displayed hours.
  • Legends Options shows the selected mode and current season without enlarging its windows.

Release-specific

No Release-only gameplay divergence; developer tools remain disabled.

v0.0.10 October 7, 2026

Shared

  • Added SHINY RATE to Legends Options with selectable 1/8192, 1/5680 and 1/1226 wild shiny base odds.
  • The selection saves with the game; older saves default to 1/8192.
  • DexNav, chain-fishing and Shiny Charm bonus rolls remain in effect. Eggs, gifts and scripted Pokémon are unaffected.
  • The General Options page and its window dimensions are unchanged.

Release-specific

No Release-only gameplay divergence; developer tools remain disabled.

v0.0.9 October 7, 2026

Shared

  • Added physical Exp. Share to Key Items, synchronized with the Legends Options toggle.
  • Unlocked DexNav alongside Birch's first Pokédex gift.
  • Existing saves receive missing Key Item and DexNav unlocks automatically.
  • Rustboro Lucky Egg and Champion Rare Candy reward remain unchanged.

Release-specific

No Release-only gameplay divergence; developer tools remain disabled.

v0.0.8.1 October 7, 2026

Shared

  • Prevented obsolete ROM validation and patch operations from overriding the latest browser file selection.
  • Prevented longer version labels from overlapping the Options header navigation hint.
  • Added BPS parser and checksum regression tests and a documented emulator QA checklist.
  • No change to core Legends gameplay.

Release-specific

No Release-only gameplay divergence; developer tools remain disabled.

v0.0.8 October 7, 2026

Shared

  • Reworked Options into General and Legends pages, switched with L/R.
  • Moved EXP SHARE to the Legends page so future project settings have dedicated space.
  • Restored the original safe window dimensions, fixing corrupted/repeating frame graphics and the clipped CANCEL row.

Release-specific

No Release-only gameplay divergence in 0.0.8.

v0.0.7 October 7, 2026

Shared

  • Professor Birch now enables the National Pokédex during the initial Pokédex handoff.
  • The post-Elite Four National Dex upgrade reward is now 25 Rare Candies.
  • If the Bag cannot hold all 25, Birch sends them to the PC; if both are full, the reward remains claimable later.
  • Existing postgame saves can claim the new reward once while preserving later Johto starter progression.

Release-specific

No Release-only gameplay divergence in 0.0.7.

v0.0.6 October 7, 2026

Shared

  • Replaced Mr. Stone's post-letter Rustboro reward with a Lucky Egg instead of the redundant held Exp. Share.
  • Updated his reward dialogue to explain the Lucky Egg's EXP bonus.
  • Lucky Egg's native multiplier behavior is unchanged; this update changes acquisition only.

Release-specific

No Release-only gameplay divergence in 0.0.6.

v0.0.5 October 7, 2026

Shared

  • Added Gen 6-style party-wide EXP Share from the start of the game, enabled by default.
  • Added an EXP SHARE ON/OFF setting to the Options menu.
  • Older saves receive a one-time migration to the new default; later player choices are preserved.
  • Native Lucky Egg, traded-Pokémon, scaled EXP, catch EXP, and level-cap handling remain intact.

Release-specific

No Release-only gameplay divergence in 0.0.5. Release includes the full EXP Share feature with developer tools disabled.

v0.0.4.2 October 7, 2026

Shared

  • Corrected homepage wording so badge-earned field moves are accurately credited to v0.0.4.
  • Added direct build-specific changelog links beside the Release and Debug downloads.
  • Tightened changelog/version consistency checks.

Release-specific

v0.0.4 October 7, 2026

Shared

  • Cut, Flash, Rock Smash, Strength, Surf, Fly, Dive, and Waterfall are now unlocked for field use by Emerald's original badge progression instead of learned HM moves.
  • Added a compact FIELD submenu for manual access to unlocked utilities, including Flash and Fly.
  • Preserved terrain, follower, map, link, and Regi-puzzle restrictions.
  • Removed Pokémon-specific HM-use messages and suppressed arbitrary Pokémon portrait banners for these utilities.
  • Dig, Teleport, Sweet Scent, and other non-HM field moves remain tied to learned moves.

Release-specific

No Release-only gameplay divergence in 0.0.4. Release includes the complete badge-field-move system with developer tools disabled.
