# Legal / Distribution Notes

Pokémon Emerald: Legends is an unofficial, non-commercial fan project.

This repository should contain source code, scripts, documentation, original project assets, and other material that can lawfully be distributed. It must not contain a commercial Pokémon Emerald ROM or other copyrighted game binary supplied from a retail copy.

Public releases should distribute source changes and/or an appropriate patch format rather than a copyrighted base ROM.

`pokeemerald-expansion` and its dependencies retain their own licenses and attribution requirements. Those upstream notices should remain intact when the project is forked.
