# Existing v0.0.46 sprites — smile and body color repair

The owner rejected the generated replacement draft and explicitly requested retaining the published v0.0.46 sprites. PR #64 now restores the master tree at `fa3b6dadfe3ed733c7db3f66181551960be1fef4` and applies only a color-compositing repair. Generated replacement artwork, portrait renderer, importers and review exports are removed from the active branch. No new images are generated and no hairstyles are redesigned. The historical v0.0.46 assets and changelog entries are retained.

Some native brown mouth/face/ear contours share slot 4 with hair. A blond or silver selection therefore colors the smile and chin as hair. Male layer 14, previously unused, now retags those protected native contours to skin shadow 3 after the existing hair layer, only while the pixel still uses slot 4. The selected skin palette supplies the color. The existing hair/coat masks and sprite silhouettes remain unchanged.

The existing body isolation layer also runs for Natural custom hair, and bare-skin contours use skin shadow instead of navy. Footwear remapping excludes both reserved hair slots for every custom male cut; non-shoe clothing shades therefore stop changing with hair color. Approved three-shade field hair and its palette remain intact. Original with no hair/color customization keeps its existing fallback. Female layers, prepared battle art, fixed costumes, native diving and saved wardrobe IDs retain their existing behavior.

`test/legends-appearance-color-baseline.json` records v0.0.46 SHA256 fingerprints for every existing hair/coat layer, every female/back layer, the male atlas and its registration metadata. Only male front/field material layers 13/14/15 may differ. Layer 15 supplies the Natural body correction while preserving its published Ball shading; selected hair colors retain their established prop treatment. The compiled-C color regression uses the actual palette update, existing outfit/accessory banks and front/field constructors; it verifies mouth/chin isolation, body RGB independence, wardrobe combinations and cached consumers. Existing anatomy, sparse geometry, footwear, palette/save, intro, wardrobe and approved battle regressions are retained.

Its original reference requires the v0.0.46 Git object when running `python test/legends-appearance-colors.test.py --preview`; the ordinary CI test does not require Git history.
